## Brand corrections

- Modal now uses the official full-color image: https://modal-cdn.com/modal-logo-icon.png (https://modal.com/blog/what-is-modals-logo).
- Claude Code uses the product-specific terracotta mascot: https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/claudecode-color.svg (Lobe Icons, MIT).
- Hugging Face uses the full-color emoji artwork: https://raw.githubusercontent.com/pheralb/svgl/main/static/library/hugging_face.svg (SVGL, MIT).
- Pydantic, LangChain, LangGraph, and Snowflake SVG fills use the brand hex values in Simple Icons metadata. Power BI uses its yellow #F2C811.
- Black-and-white brands, including Cursor and GitHub, retain their monochrome artwork.

Brand logos identify the named technologies; trademarks belong to their owners.
Devicon artwork: https://github.com/devicons/devicon (MIT).
Simple Icons artwork: https://github.com/simple-icons/simple-icons (CC0; individual brand terms may apply).
Seaborn artwork: https://seaborn.pydata.org/ (project logo).
SQL, CI/CD and REST APIs are concepts without a single brand logo; their images are Lucide database, workflow and network icons (ISC).
