# Project link icons

- GitHub uses the same Font Awesome Brands `fa-github` icon as the hero.
- Devpost: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/devpost.svg (Simple Icons, CC0).
- The Devpost mark was checked against its source artwork: https://github.com/challengepost/supportcenter/blob/e40066cde2ed25dc14c0541edb746ff8c6933114/images/devpost-icon-rgb.svg.
