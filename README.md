My personal website with my projects, experience, and a bit about me. Built with TypeScript and Vite.

## File structure

```
.
├── index.html
├── src/
│   ├── main.ts             # Site content and rendering

│   └── skill-logos.ts      # Technical skill logos
├── public/
│   ├── logos/              # Company and skill logos
│   ├── projects/           # Project images
│   └── reports/            # Project reports
├── docs/                  # Project sources
├── package.json
├── tsconfig.json
└── vite.config.ts
```
